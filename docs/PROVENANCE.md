# Provenance

Reference cohort: Lloyd-Price et al. (2017), *Strains, functions and dynamics in the expanded Human Microbiome Project*, Nature 550:61–66. PMID: [28953883](https://pubmed.ncbi.nlm.nih.gov/28953883/). DOI: [10.1038/nature23889](https://doi.org/10.1038/nature23889).

The three supplied HMP1-II inputs are taxonomic relative-abundance profiles, EC relative-abundance profiles, and public sample metadata. Archive filenames and content hashes are recorded in the manifest. Public HMP identifiers and associated cohort metadata are retained. The taxonomic table identifies the MetaPhlAn database version in its header. These processed inputs should not be described as the exact original 2017 profiling release without verifying processing provenance.

The exact upstream download URLs and redistribution terms of these supplied processed files have not been established. No new license or ownership claim is applied to third-party data. This prototype does not assign a software license; select one before offering licensed reuse.

The implementation originated from a locally developed power-planning workflow informed by the BioBakery power app (https://biobakery.shinyapps.io/power/). Numerical methods, filters, and limitations are described in METHODS.md. This repository is a fresh export and does not include prior project history.
